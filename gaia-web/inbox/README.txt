GAIA Inbox — CSV 파일을 여기에 넣으세요.

폴더 구조
  inbox/grr/                    GRR 분석
  inbox/liw/                    LIW 분석
  inbox/temperature/            Temperature Tracking
  inbox/tact-time/Station1~8/   Tact Time (Station별)
  inbox/error-analysis/         Error Analysis
  inbox/config/                 GRR Config (GaiaStat2grrConfig)

사용 방법
1. 탐색기에서 해당 폴더에 CSV 복사
2. GAIA 실행 → 해당 메뉴 → Inbox에서 [최신 파일 불러오기]
   (Tact Time은 Station 선택 후 해당 Station 폴더 사용)

※ 회사 보안 프로그램으로 브라우저 업로드가 막혀도 이 방식은 동작합니다.
